Frames injected with oversized payload headers (>100 bytes) designed to cause gateway ring buffer overflows and parser faults.

Faculty Defense Strategy & Key Talking Points

Q: Why not just use cryptographic MIC verification?
Answer: MIC checks occur at the Network Server. If an attacker floods the gateway with invalid or replayed MICs, the gateway’s duty-cycle and backhaul bandwidth are already exhausted. Physical layer IDS operates at the edge gateway to drop rogue packets before they saturate network resources.

Q: How does the system handle moving or fading nodes without false alarms?
Answer: The system does not rely on a single stateless threshold. It uses rolling temporal inter-arrival time (IAT) combined with 7-parameter decision trees (RSSI + SNR + SF + IAT + FCnt + Payload + Freq), maintaining an ultra-low False Positive Rate under natural fading.
